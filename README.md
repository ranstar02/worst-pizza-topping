> Introducing the 'Landfill Special': a pizza topped with soggy chips, one lost fish finger, and a mystery meat the menu legally can't name — served with a side of regret and a tetanus waiver.

An entry for "The Worst Pizza Topping" bounty on make.fun ($2 in USDC) — one funny line pitching a genuinely terrible pizza topping: the Landfill Special, a pizza no menu can legally describe and no stomach should ever meet.

## How it works

The program is deterministic, standard library only, with no network access. It validates the line first (non-empty, single line, no control characters, at most 200 characters), then writes the 190-character line to `/output/entry.txt` (falling back to `./output/entry.txt` if `/output` cannot be written), with no trailing newline.

## Run it

```sh
python3 main.py
```
